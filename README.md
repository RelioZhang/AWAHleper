# AWAHelper · 爱华声级计数据处理

AWA6228+ 声级计数据的处理工具集。

## 目录结构

```
AWAHelper/
├── data-manager/          # 数据管理模块（网页界面）
│   ├── server.py          # 本地服务：扫描目录、解析 AWA、导出表格
│   ├── web/               # 前端界面（HTML/CSS/JS，零依赖）
│   └── 启动数据管理.bat    # 双击启动
└── .gitignore
```

## data-manager：数据管理模块

按「数据分类 → 文件列表 → 频谱曲线」三层结构查看 AWA 数据。

提供两种界面，功能完全一致，共用同一套解析与存储逻辑：

| 版本 | 入口 | 依赖 |
|---|---|---|
| 桌面版（推荐） | `启动桌面版.bat` | `pip install PySide6` |
| 网页版 | `启动数据管理.bat` | 无（纯标准库） |

### 桌面版

真正的 Windows 窗口程序，不是网页。

```
双击 启动桌面版.bat
```

或用 pythonw 直接跑（不弹黑窗）：

```bash
pythonw desktop.py
pythonw desktop.py --dir D:\某批数据
```

首次使用需安装界面库（仅一个）：

```bash
pip install PySide6
```

#### 打包成 exe

双击 `打包exe.bat`，脚本会自动装 PyInstaller 并生成：

```
dist\AWA数据管理.exe
```

这个 exe 可单独拷给同事，对方电脑**不需要装 Python**。

### 网页版

```
双击 启动数据管理.bat
```

或 `python server.py --dir D:\数据 --port 8765`，浏览器访问 `http://127.0.0.1:8765`。

### 选择数据目录

每次测试数据放在不同文件夹，程序目录与数据目录相互独立：

- 点【设置】→【浏览…】选择本次测试数据所在的文件夹
- 读取成功的目录自动记住，下次启动直接打开
- 设置面板保留最近 8 个目录，可一键切换
- 选错目录（里面没有 AWA）时，会列出该目录下检测到的数据文件夹供切换

### 支持的数据类型

| 分类 | 来源 | 说明 |
|---|---|---|
| 1/3 OCT 数据 | `1_3_*.AWA` | 33 个频带 × 5 组统计量，可绘频谱曲线 |
| OCT 数据 | `OCT_*.AWA` | 倍频程，同上 |
| 统计汇总数据 | `STA_*.AWA` | Leq/Lmax/Lmin/L10~L95/SD/SEL，柱状图 |
| 声级分布数据 | `NUM_*.AWA` | 声级-百分比分布曲线 |
| 总值数据 | 由频谱文件提取 | A/C/Z/U/T/B 各计权总值，128 条/批起 |

FFT、24H、瞬时类数据当前数据批次未导出，显示为 0。

WAV 录音文件不参与处理。

### 修改数据（不碰原文件）

单元格**双击即可编辑**：测点名、测试日期、测试时间、各项声级。
带浅绿角标的单元格可编辑；频谱曲线上单击任一数据点也能改该频带值。

> **原始 .AWA 文件永远不会被改写。** 修改以「文件名 → 字段 → 新值」的形式
> 存进数据目录下的 `.awa-edits.json` 侧车文件，读取时叠加显示，导出也带改后的值。
> 删掉这个文件或点【撤销修改】即完全还原。已用 SHA256 校验：改前改后原文件字节一致。

#### 同组联动

`1_3_0001` / `OCT_0001` / `STA_0001` / `NUM_0001` 是**同一次测量的四种导出视图**，
所以元数据必须一起改，否则三类表格里对不上：

| 字段 | 联动 |
|---|---|
| 测点名、测试日期、测试时间 | ✅ 同步到同编号的全部文件（四个分类一起变） |
| SPL(A/C/Z/U/T/B)、STA 统计量、频带值、分布值 | ❌ 只改当前文件（数值本就各不相同） |

带右上角小蓝点的单元格就是联动字段。在其他分组里的同编号文件不受影响。

修改过的单元格底色变黄并带左侧色条，便于辨认。

### 排序与筛选

- **排序**：点任意表头，升序 → 降序 → 取消，循环切换；空值恒排末尾。
  **排序状态会记住**：按分类分别保存，关掉浏览器再打开仍然保留（存在 localStorage）。
- **筛选**：点【筛选】打开条件面板，可叠加多条「并且」条件，支持
  包含 / 不包含 / 等于 / 不等于 / 大于 / 大于等于 / 小于 / 小于等于 / 介于 / 为空 / 不为空。
  例：`测点名 包含 会议室` + `SPL(A) 大于 50` + `测试日期 等于 2026-11-02`。
- 顶部搜索框可在所有列里快速查找，与条件筛选同时生效。
- 面板底部实时显示「符合条件 N 行 / 共 M 行」。

### 文件格式

AWA 导出文件为 GBK 编码、TAB 分隔的文本：

```
Model:AWA6228+	 Serial:00311376
R:20dB-132dB	 Ts=00h00m10s	 Wei:Z
Calibrate@2025-07-09 17:19:14 Lx=-28.8dB
测点名	测试日期	测试时间	方式	经历时间	指标	6.3Hz	8Hz	...	SPL(Z)
DATA_0641	2026-11-02	13:58:54	1/3 OCT	00h00m10s	Leq,T	...	67.9
```

解析要点：以含「测点名」的行作为表头，频率列按 `12k5Hz` / `31.5Hz` 这类写法换算为 Hz；`---.-`、`--` 视为空值。

## 数据安全

程序只读数据目录，不会修改或删除原始 AWA 文件。
